Failure:
  tests::receive_paths_stay_inside_root
  accepted /tmp/outside.txt

Root cause:
On Windows, Rust's Windows Path implementation does not treat a slash-only
path such as /tmp/outside.txt as an absolute path. The cross-platform receive
path helper checked Path::is_absolute() but did not independently reject a
leading slash.

Fix:
safe_receive_path now rejects leading '/' and '\\' in addition to absolute
paths, drive/colon paths, backslashes, NUL, and parent-directory components.
